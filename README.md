# ARMA Time Series Analysis (R)
An academic project based on real-world panel data , focusing on econometric time series analysis and implemented in R.

## Overview
This project presents an analysis of AutoRegressive Moving Average (ARMA) models within the context of time series analysis.

The study combines theoretical foundations with practical implementation in R, supported by an HTML report containing visualizations and results.

## Objectives
- To understand the theoretical structure of ARMA processes
- To implement ARMA modeling in R
- To analyze time series behavior using visual tools

## Methodology
The project focuses on:
- AR (AutoRegressive) components
- MA (Moving Average) components
- Combined ARMA modeling approach

Implementation was carried out in **R**, leveraging standard time series analysis techniques.

## Output
The main output of this project is an HTML report including:
- Model explanation
- Data analysis
- Visualizations
